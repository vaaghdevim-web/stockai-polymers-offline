2. Audit Findings & Resolution Matrix

Audit Finding & Severity Pre-Audit Issue Implementation Resolution Status
CRITICAL: Hardcoded JWT Secret Default fallback in application.properties Removed all fallbacks; created fail-closed ProductionSecurityValidator.java (>=256 bits check). FIXED
CRITICAL: Redis Default Password Plaintext Redis credentials committed Removed default password; enforced mandatory REDIS_PASSWORD. FIXED
CRITICAL/HIGH: IoT Shared Key Model Single global key; privilege escalation to OPERATOR Created DeviceRegistryService with SHA-256 hashed keys, lifecycle states, and ROLE_MACHINE isolation. FIXED

HIGH: Insecure Nginx Proxy No login rate-limiting; HSTS over plain HTTP Added TLS 1.2/1.3, HTTPS redirect, HSTS, and 10 req/min login rate limiting. FIXED
